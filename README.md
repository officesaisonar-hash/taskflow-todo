# 🚀 TaskFlow — To-Do Application

A modern and responsive task management application built with HTML, CSS, and JavaScript.

TaskFlow was created as my first JavaScript project to understand **CRUD operations, DOM manipulation, event handling, and browser LocalStorage**.

## ✨ Features

- ✅ Create new tasks
- 👀 View all tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ☑️ Mark tasks as completed
- 💾 Persistent data using LocalStorage
- 🔍 Task filtering
- 📱 Responsive design
- 🌙 Modern user interface

## 🧠 What I Learned

This project helped me understand the fundamentals of JavaScript through a real-world application.

### CRUD Operations

**Create**
- Add new tasks to the application.

**Read**
- Display stored tasks dynamically on the page.

**Update**
- Edit tasks and change their completion status.

**Delete**
- Remove tasks from the application.

- Conditional logic
